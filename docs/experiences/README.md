# Experiences

Experiences descrevem uma jornada específica quando o detalhe funcional não cabe
em `EPICS.md` nem em `Product/USER_JOURNEYS.md`.

Elas são documentos derivados: não definem prioridade, arquitetura ou estado do
MVP. Uma Experience só deve existir quando possuir objetivo, usuários, problema,
fluxo, integrações, critérios de aceite e vínculo com o `MVP_PLAN.md`.

- [`assessments.md`](./assessments.md).
